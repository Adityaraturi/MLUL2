# MLUL2

Repository scaffold for MLUL2 recommendation and anomaly detection assignment.

## Project Structure

```
MLUL2/
│
├── data/
│   ├── all_except_last_orders.csv
│   ├── last_orders_subset.csv
│   └── company_performance.csv
│
├── submissions/
│   └── GR_n_rec_5_sets.csv
│
├── GR_n_MLUL2_Recsys.ipynb
├── GR_n_MLUL2_Anomalies.ipynb
│
├── report/
│   └── Group-nn_report.pdf
│
├── Assignment_Submission_Form.pdf
└── README.md
```

## Team Usage Notes

- Replace `n`/`nn` in file names with your group number before final submission.
- Keep notebooks fully executed and error-free before submission.
- Use `submissions/` only for final recommendation output files.
